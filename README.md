# Carpe Diem

생년월일과 평균 기대수명으로 남은 시간을 보여주는 iOS 위젯 중심 앱.

## 진행 상황

| 단계 | 상태 |
|---|---|
| 디자인 방향 결정 | 진행 중 — 5번 자연(올리브) + 은은한 빛 + 유리 효과로 통합 시안 검토 |
| 오늘의 명언 데이터 | 주제에 맞게 26개 유지, 74개 교체 — 검토 대기 |
| 앱 · 위젯 개발 | 디자인 확정 후 시작 |
| 앱스토어 등록 | 개발 후 |

## 폴더

- `data/quotes.csv` — 오늘의 명언 100개 (번호, 한글, 영문)
- `docs/quotes.md` — 명언을 고르고 보여주는 규칙
