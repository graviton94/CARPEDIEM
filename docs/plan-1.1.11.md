## 결정한 것

- 앱이 직접 구글 드라이브에 올리는 백업 (Drive API) 은 하지 않음: 구글 로그인 · 네트워크 권한 · 서버 쪽 설정이 들어와 ‘계정 · 서버 없음’ 과 맞지 않음. 대신 폰의 구글 자동 백업 (1.1.10 부터 사진 포함) 을 보이게 하고, 파일 저장은 드라이브로 가는 길을 안내.

## 폰에서 볼 것

- 설정 › 백업 · 옮기기 세 줄, 각 안내 문구 (네 말)
- 백업 파일로 저장 → 안내 → ☰ › Drive 에 저장 → 불러오기에서 Drive 로 다시 찾기
- 기록 › 달의 정원 › 사진 있는 지난 날 · 보낸 사람 있는 날 · 글만 있는 날 → 이 날을 그림으로 보내기
