# Carpe Diem 프로젝트 계획서

작성 2026-09-30 · 방향이 바뀌면 이 문서를 먼저 고칩니다.

## 1. 비전과 원칙

**남은 시간을 보여주는 이유는 두려움이 아니라, 오늘을 소중히 여기기 위해서입니다.**

1. **핵심 기능은 언제나 무료.** 남은 시간, 위젯, 오늘의 문장, 나라별 기대수명.
2. **결제는 꾸미기와 응원만.** 광고 없음. 결제해야만 쓸 수 있는 핵심 기능 없음.
3. **기록은 기기에만.** 서버·계정·추적 없음. (동기화를 넣는다면 사용자의 iCloud · Google 백업만)
4. **불안을 주지 않는 업적.** 연속 기록 끊김 알림이나 벌 없음. 삶의 순간을 기념합니다.
5. **담담하고 짧게.** 문구, 캐릭터, 효과 모두 조용하게.

## 2. 캐릭터 — 하루

오늘 하루만큼 살다 가는 아주 작은 정령. 앱을 열면 그날의 문장 곁에 조용히 앉아 있습니다.

| 항목 | 정의 |
|---|---|
| 이름 | **하루** (Haru) — ‘하루(一日)’ |
| 크기감 | 쌀알이나 씨앗만 한 크기. 화면에서도 작게, 여백 속 한 점처럼 |
| 몸 | 매끈하고 둥근 물방울 모양, 따뜻한 미색. 테두리 없이 면으로만 |
| 얼굴 | 점 눈 두 개, 가끔 발그레한 볼. 입은 거의 없음 |
| 머리 | 올리브 새싹 한 잎 (앱 강조색) |
| 몸짓 | 통통 튀기, 꾸벅 졸기, 잎 흔들기, 문장 옆에 앉기 — 느리고 작게 |
| 계절 | 인생의 계절에 따라 잎이 바뀜: 봄 연두 새싹 · 여름 무성한 잎 · 가을 단풍잎 · 겨울 작은 목도리 |
| 참고한 분위기 | 작은 먼지 정령, 테루테루보즈의 ‘작고 조용한 존재’ 느낌 |
| 피할 것 | 기존 캐릭터와 닮은 모습 — 검은 털뭉치, 천 · 끈 인형 모양. 이름과 생김새 모두 새로 만든 것이어야 합니다 (저작권) |

제작: 단색 면 벡터(SVG)로 그려 iOS·Android 양쪽에서 씁니다. 먼저 시안 3종을 만들어 고릅니다.

## 3. 단계별 계획

| 단계 | 버전 | 내용 | 사용자가 할 일 | 상태 |
|---|---|---|---|---|
| M0 | — | 디자인 확정, 명언 100개, 기대수명 238개 나라, iOS 앱 · 위젯, 화면 캡처 자동화 | — | ✅ 완료 |
| **M1** | Android 1.0 | 앱 4화면 + 위젯 3종, APK를 GitHub 릴리스로 배포 → 내 폰에 설치 | 폰에서 APK 받아 설치 · 사용 후기 | 🔨 진행 중 |
| M2 | 1.1 | **하루 등장**: 캐릭터 시안 3종 → 선택 → 앱 홈 · 위젯에 배치, 계절별 모습 | 시안 고르기 | 계획 |
| M3 | 1.2 | **후원**: “커피 한 잔” 소액 결제 3단계, 후원 감사 소품 | 금액 정하기 | 계획 |
| M4 | 2.0 | **하루의 작은 정원**: 정원 화면, 소품 배치, 업적, 테마 색, 위젯 스타일, 아이콘 변형 | 소품 · 테마 우선순위 | 계획 |
| M5 | — | **스토어 출시**: Google Play, App Store | 개발자 계정 가입 | M1 사용 후 결정 |
| M6 | 2.x | 확장 후보: 기기 변경 시 옮기기(백업), 오늘 한 줄 기록, 계절 알림 | — | 아이디어 |

순서는 바꿀 수 있습니다. 예를 들어 M1 후 바로 M5(Play 출시)를 할 수도 있습니다.

### M1 Android 1.0 — 완료 기준
- 폰에서 APK를 설치하고, 온보딩 → 홈 → 설정 → 나라 선택이 모두 됨
- 위젯 3종(남은 날 2×2, 오늘 2×2, 인생 달력 4×2 · 4×4)을 홈 화면에 둘 수 있음
- 자정에 오늘의 문장이 바뀌고, ‘오늘’ 위젯이 한 시간마다 갱신됨
- 한국어 · 영어, 라이트 · 다크
- iOS와 같은 디자인 토큰 · 문구 · 데이터를 씀 (`design/`, `data/`에서 자동 생성)

### M2 하루 등장
- 시안: 정면 · 앉기 · 졸기 세 자세 × 스타일 3종을 비교 페이지로
- 앱 홈: 오늘의 문장 카드 가장자리에 하루가 앉아 있음. 문장을 넘기면 꾸벅
- 위젯: 남은 날 위젯 한쪽에 아주 작게 (켜고 끄기 가능)
- 인생의 계절에 따라 잎 모양이 바뀜

### M3 후원
- 한 번 결제 3단계 (예: 1,500 · 4,400 · 11,000원). 반복 결제 없음
- 후원 후 감사 소품 하나 (예: 따뜻한 찻잔). 나머지는 똑같이 씀
- Android Play Billing, iOS StoreKit 2. 구매 기록만 기기에 저장

### M4 하루의 작은 정원
작은 창가 정원 하나. 하루가 살고, 삶의 순간마다 소품이 하나씩 늘어납니다.

**업적 (무료, 기기 안에서 날짜로 판정)** — 초안

| 분류 | 업적 |
|---|---|
| 시작 | 처음 연 날 · 처음 위젯을 둔 날 · 처음 문장을 넘긴 날 |
| 시간의 이정표 | 태어난 지 10,000일 · 15,000일 · 20,000일 · 25,000일, 남은 날 10,000일 |
| 계절 | 인생의 봄 → 여름 · 여름 → 가을 · 가을 → 겨울로 넘어간 날 |
| 해마다 | 생일 · 새해 첫날 · 한 해의 절반(7월 2일) · 한 해의 마지막 날 |
| 문장 | 오늘의 문장 100일 한 바퀴 · 같은 문장을 두 번째로 만난 날 |
| 함께한 시간 | 앱과 함께한 30일 · 100일 · 1년 (연속이 아니라 누적) |

**꾸미기 · 수집** — 초안

| 종류 | 예 | 얻는 법 |
|---|---|---|
| 하루의 모습 | 계절 잎, 작은 모자, 목도리, 우산 | 업적 · 계절 |
| 정원 소품 | 화분, 등불, 책 한 권, 작은 의자, 찻잔, 창밖 풍경 | 업적 · 후원 |
| 테마 색 | 올리브(기본) · 새벽 · 바다 · 단풍 · 눈 · 밤 | 업적 · 후원 |
| 위젯 스타일 | 달력 점 모양(원 · 잎 · 별), 정원 위젯, 배경 | 업적 · 후원 |
| 앱 아이콘 | 엔소 · 궤도의 계절 색 판 | 업적 |

## 4. 기술 설계

```
design/tokens.json, design/strings.json, data/*.csv   ← 유일한 원본
        │  scripts/generate.py
        ├── ios/     Swift 토큰 · 문구 · 리소스
        └── android/ Kotlin 토큰 · strings.xml · assets
```

| 영역 | iOS | Android |
|---|---|---|
| 앱 | SwiftUI | Jetpack Compose |
| 위젯 | WidgetKit | Glance (격자 · 링은 비트맵으로 그림) |
| 계산 로직 | `Shared/Model` | `android/core` (순수 Kotlin, 로컬 테스트 가능) |
| 저장 | App Group UserDefaults | SharedPreferences |
| 결제 (M3) | StoreKit 2 | Play Billing |
| 캐릭터 · 소품 (M2~) | SVG → 에셋 카탈로그 | SVG → VectorDrawable |
| 테마 (M4) | 토큰 색 묶음 여러 벌 | 같음 |

- 업적 엔진: 날짜 · 생일 · 기대수명 · 사용 기록(처음 연 날, 문장 넘긴 수)만으로 판정. 서버 없음
- 모든 새 문구는 `design/strings.json`에 한/영 함께 추가 (CI가 누락 검사)

## 5. 배포와 비용

| | Android | iOS |
|---|---|---|
| 내 폰 테스트 | **무료** — GitHub 릴리스의 APK 설치 | 연 $99 + TestFlight |
| 스토어 출시 | Google Play 1회 $25 | 같은 연 $99로 가능 |
| 주의 | 새 개인 계정은 출시 전 **테스터 12명이 14일 동안 비공개 테스트**해야 함 | 심사 1~3일 |

수익은 필수가 아닙니다. 후원 · 꾸미기 수익으로 연 $99를 메우려면 2,200원 결제 기준 연 80건 정도가 필요합니다.

## 6. 위험과 대응

| 위험 | 대응 |
|---|---|
| 캐릭터가 기존 작품과 닮음 | 이름 · 생김새 새로 디자인, 시안 단계에서 비교 확인 |
| 업적이 압박이 됨 | 연속 기록 없음, 알림은 기본 꺼짐, 놓쳐도 사라지지 않음 |
| 꾸미기가 앱의 담담함을 해침 | 정원은 별도 화면. 홈 · 위젯은 기본적으로 조용하게 |
| Play 비공개 테스트 12명 모집 | M1 APK로 지인 테스트를 미리 시작 |
| 두 플랫폼 기능 차이 | 원본 파일 공유 + 같은 테스트 예시로 맞춤 |
