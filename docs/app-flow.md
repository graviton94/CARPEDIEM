# 앱 흐름: 정원이 곧 홈

정원은 따로 있는 기능이 아니라 지금 앱의 홈 그 자체입니다. 계산 · 데이터 · 명언 · 설정 항목은 그대로이고, 보여 주는 방식만 바뀝니다.
시안: 앱 흐름 아티팩트 (온보딩 → 하루를 만남 → 홈 → 아래로 → 놓인 것 → 설정, 위젯 4종).

## 세 가지 연결
- **땅 한 줄 = 지나온 길.** 왼쪽 끝 태어난 날, 오른쪽 끝 기대수명. 하루는 `x = 진행률` 자리에 앉아 해마다 조금씩 오른쪽으로 갑니다. 받은 것은 지나온 쪽(하루 왼쪽)에 놓입니다.
- **해 = 오늘이 지난 만큼.** 흐르는 시간 · 오늘의 비율로 해가 왼쪽 낮게 → 높이 → 오른쪽 낮게. 밤에는 달.
- **하늘빛 · 땅빛 = 인생의 계절** (진행률 × 4). 봄에는 하루 머리에 새싹.

## 지금 앱 → 새 앱
| 지금 앱 | 새 앱 |
|---|---|
| 남은 시간 카드 + 단위 | 하늘 위의 큰 숫자와 일 · 주 · 개월 · 년 칩 |
| 오늘의 문장 카드 | 숫자 아래 하늘에 문장만. 누르면 다음 문장, 하루가 깜빡 |
| 지나온 길 (나이 · 계절 · 기대수명) | 땅 한 줄. 양 끝 0세 · 기대수명, 하루 아래 ‘만 N세 · 인생의 계절’ |
| 흐르는 시간 4줄 | 해의 자리(오늘) + 아래로 넘기면 크레용 막대 4줄 |
| 인생 달력 | 아래로 넘긴 종이 위 손으로 칠한 칸. 지나온 칸은 계절 색, 지금은 호박색 |
| 온보딩 | 같은 항목을 크레용 칸으로 + 끝에 ‘하루를 만났습니다’ 한 장 |
| 설정 | 같은 항목 + 내 하루 · 테마 6 · 간결한 홈(정원 끄기) · 응원하기 |
| 위젯 3종 · 잠금 화면 | 같은 3종을 새 그림체로 + 큰 크기 정원. 잠금 화면은 글자만 |
| 올리브 빛 · 유리 카드 | 종이 바탕 · 크레용 선 상자. 올리브는 강조색으로 남김 (결정 필요) |

## 정할 것
1. ‘올리브 빛 + 유리 효과’ → 종이 바탕 + 크레용 선 (추천)
2. 홈 = 정원 + 설정에 ‘간결한 홈’ (추천)
3. 놓인 것이 생긴 날 알림 (기본 끔 추천)
4. 응원하기는 보상 없이 (추천)
