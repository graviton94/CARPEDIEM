# 디자인 — 올리브 빛

확정일: 2026-09-30
시안: `design/mockup.html` (브라우저로 열면 언어·기기·모드를 바꿔 볼 수 있음)

## 철학

- **카르페 디엠.** 남은 시간을 보여주는 이유는 두려움이 아니라 오늘을 소중히 여기기 위해서입니다.
- **담담하고 짧게.** 문구는 설명하지 않고 말합니다. “오늘을 소중히.” “기록은 이 기기에만 머뭅니다.”
- **한 화면, 한 위젯, 한 가지.** 각 위젯은 한 가지만 보여줍니다.

## 시각 방향

| 요소 | 결정 |
|---|---|
| 바탕 | 올리브와 돌색 (초안 5번 자연) |
| 빛 | 화면 위쪽에서 햇빛처럼 번지는 은은한 그라디언트. 큰 숫자, 진행 막대 끝, 달력의 ‘지금’ 칸만 살짝 빛남 (초안 4번) |
| 유리 | 카드·입력 칸이 반투명 유리 (초안 2번). 위젯은 실제 투명이 불가능하므로 불투명 그라디언트와 윤곽 하이라이트로 표현 |
| 계절 | 인생 달력을 봄·여름·가을·겨울로 물들여 지금이 인생의 어느 계절인지 표시 |
| 서체 | 숫자·제목·문장은 Lora + Noto Serif KR(앱에 쓰는 글자만 남긴 부분 폰트, OFL), 본문은 시스템 서체 |
| 아이콘 | **엔소 · 궤도.** 가늘고 온전한 원(영원) 위에 굵고 열린 붓길(한 번뿐인 삶), 열린 자리의 한 점(오늘). 단색 면만 사용 |

## 토큰

모든 크기·글자·색·모서리는 `design/tokens.json`에서만 가져옵니다. 화면 코드에 숫자나 색을 직접 쓰지 않습니다.

- 글자는 iOS Dynamic Type 이름(`largeTitle`, `body` …)과 1:1이며 Android Material 이름도 함께 적어 둡니다.
- 기기 크기 등급 `compact`(< 390pt, iPhone SE · 12 mini · 13 mini) · `regular` · `large`(≥ 430pt)에 따라 큰 숫자 크기와 화면 여백만 바뀝니다.
- 위젯은 OS가 알려주는 실제 크기를 쓰고, 안쪽 여백은 `widgetPadding`(16)입니다.
- 문구는 `design/strings.json`에 한국어·영어를 같은 키로 둡니다.

## 화면

1. **온보딩** — “Carpe Diem / 오늘을 소중히.” 생년월일, 나라(기기 지역으로 자동), 성별, 기대수명(자동/직접), [시작]
2. **앱 홈** — 남은 시간(일·주·개월·년) → 오늘의 문장 → 지나온 길 → 흐르는 시간(오늘·이번 주·이번 달·올해) → 인생 달력(기본 1칸 = 1개월)
3. **설정** — 나의 정보, 기대수명, 문장 언어, 위젯 안내, 모든 기록 지우기
4. **나라 선택** — 검색 + 목록, 나라·성별별 기대수명 표시

## 위젯

| 위젯 | 크기 | 내용 |
|---|---|---|
| 남은 날 | 작게 | 남은 일수(단위 선택 가능), 진행 막대, 인생의 계절 |
| 오늘 | 작게 | 오늘이 지나간 비율을 링으로, 남은 시간 |
| 인생 달력 | 중간 | 남은 해 + 1칸 = 1년 격자 |
| 인생 달력 | 크게 | 1칸 = 1개월 격자 + 오늘의 문장 |
| 잠금 화면 | 원형 · 직사각형 · 한 줄 | 인생 진행률, 남은 날·주 (iOS만) |

틀은 같습니다. 왼쪽 위에 이름, 가운데에 핵심 숫자나 그림, 아래에 보조 정보가 옵니다.

## 기대수명 데이터

- 기본값: 기기 지역 → 나라, 나라 × 성별 평균 기대수명. 사용자가 직접 입력할 수 있습니다.
- 출처: UN 세계인구전망(World Population Prospects) 2024, 2023년 0세 기대수명(Medium), 238개 나라·지역 + 세계 평균.
- 나라 이름은 iOS·Android가 기기 언어로 제공하는 이름을 씁니다.
- 갱신: GitHub Actions의 `Life expectancy data` 워크플로를 실행하면 `data/life-expectancy` 브랜치에 새 자료가 올라옵니다. 검토 후 main에 합칩니다.
- 참고: UN 추정치는 나라 통계청 값과 조금 다를 수 있습니다. 예를 들어 한국은 UN 84.3세, 통계청 2023년 생명표 83.5세입니다.

## 플랫폼

- iOS: SwiftUI + WidgetKit (iOS 17 이상). 먼저 출시합니다.
- Android: Jetpack Compose + Glance. 잠금 화면 위젯이 없어 ‘오늘의 문장’ 알림(선택)으로 대신합니다.
- 공통: `design/tokens.json`, `design/strings.json`, `data/quotes.csv`, `data/life-expectancy.csv`, 계산 규칙과 테스트 예시.
