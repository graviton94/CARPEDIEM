# 안드로이드 폰에 설치하기 (무료, 컴퓨터 필요 없음)

1. 폰 브라우저(Chrome)에서 GitHub에 로그인한 상태로 아래 주소를 엽니다.
   https://github.com/graviton94/CARPEDIEM/releases/tag/android-latest
2. **Assets** 아래 `CarpeDiem-숫자.apk` 를 눌러 받습니다.
3. 다운로드 알림을 누르면 “이 출처의 앱 설치를 허용할까요?” 가 뜹니다 → **설정 → 이 출처 허용** 을 켜고 뒤로 가서 **설치**.
   - Play 프로텍트가 “알 수 없는 앱” 경고를 띄우면 **자세히 → 무시하고 설치** 를 누릅니다. (Play 스토어를 거치지 않은 앱이라 뜨는 경고입니다)
4. 앱을 열고 생년월일을 넣습니다.
5. 위젯: 홈 화면 빈 곳을 길게 누름 → **위젯** → **Carpe Diem** 에서 끌어다 놓기.

## 업데이트
같은 주소에서 새 APK를 받아 설치하면 기존 앱 위에 덮어씁니다. 입력한 정보는 그대로 남습니다.

## 참고
- 이 APK는 테스트용 키로 서명되어 있습니다 (`android/keystore/README.md`). Google Play 출시용은 따로 만듭니다.
- 최소 Android 8.0 (API 26).
