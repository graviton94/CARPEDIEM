## 0. 네 페이지 (1.9) — 먼저 읽기
홈은 이제 옆으로 넘기는 네 장이에요. 아래 이름표를 눌러도 되고 옆으로 밀어도 돼요. 아래 항목들에 남은 ‘둘째 장’ 은 이렇게 읽어 주세요.

## 처음 온 사람의 안내

- [ ] 처음 켜면 소개 석 장 (해 · 깃털 · 내 돌), 건너뛰기 있음 → 생년월일 · 나라
- [ ] 생년월일을 고르기 전에는 ‘골라 주세요’, ‘시작’을 누르면 한마디만 (넘어가지 않음)
- [ ] 하루를 만난 뒤 첫 정원: 둘러보기 9장 (남은 시간 · 문장 · 하루 · 땅 한 줄 · 아래 버튼 · 이름표 · 설정을 차례로 비춤). 아무 데나 눌러도 다음, 뒤로 가기 · 건너뛰기로 끝
- [ ] 마지막 장 ‘한 줄 쓰러 가기’ → 기록 페이지. 둘러보기를 마친 뒤에야 알림 허락 (먼저 무엇을 받는지 한 장)
- [ ] 기록 · 추억 · 흐름 · 돌의 페이지에 처음 들어가면 맨 위에 안내 한 장, ‘알겠어요’ 뒤로는 나오지 않음
- [ ] 설정 › 안내 다시 보기 → 정원에서 둘러보기부터 다시

## 네 장

| 페이지 | 있는 것 (예전 둘째 장에서 옮겨 옴) |
|---|---|
| 정원 | 남은 날 · 오늘의 문장 (질문 날엔 질문, ‘한 줄로 답하기’ 는 기록으로) · 돌들. 아래에 생일 한 줄 · 도착한 것 한 장 (편지 · 달과 해의 정원) · 숨, 쉼 · 돌멍하기 · ＋ 돌 |
| 기록 | 계절 첫날의 바람 · 오늘의 한 줄 (‘한 줄 남기기’, 다섯 줄까지) · 몇 해 전 오늘 · 마음의 기록 (월 · 해, 테두리 안) |
| 추억 | 모은 것 (계절 앨범 · 한 해 한 장 · 놓인 것 · 받은 편지 · 고마움 책 · 지난 정원 · 기억의 자리) |
| 흐름 | 흐르는 시간 · 인생 달력 · 특별한 날 (‘＋ 특별한 날 꽃 놓기’ 버튼) |

- [ ] 네 장을 밀어서 · 이름표로 오감. 돌 페이지 · 기억의 자리에 갔다 돌아오면 보던 페이지 그대로
- [ ] 도착한 것 카드는 정원 아래 (엄지가 닿는 곳), 누르면 편지 / 기록의 그 달 · 그 해
- [ ] 기록 › 해: 열두 달 무늬가 한 화면에 멈춰 있음, 달을 누르면 그 달
- [ ] 돌 고치기 아래 ‘이 돌 정리하기’: 기억의 자리로 모시기 · 정원에서 빼기, 각각 설명 한 줄 · 한 번 더 묻기
- [ ] 응원하기는 설정 안에

## 1. 처음 켜기
- [ ] 생년월일 · 나라 · 성별을 넣고 **시작** → “하루를 만났습니다.” 화면 (반짝이는 여기서만)
- [ ] 1~2초 “하루를 그리는 중…” 뒤에 하루가 나타남 → **정원으로**

## 2. 정원 (홈)
- [ ] 하늘에 남은 시간, 일 · 주 · 개월 · 년 칩, 오늘의 문장
- [ ] 문장을 누르면 다음 문장 + 하루가 한 번 깜빡임
- [ ] 땅 한 줄 = 지나온 길: 왼쪽 0세, 오른쪽 기대수명, 하루 아래 ‘만 N세 · 인생의 계절’
- [ ] 해(밤에는 달)가 지금 시각 자리에 있음. 밤 10시 ~ 아침 6시엔 하루가 졸린 눈
- [ ] 하늘빛이 시각을 따라 바뀜: 새벽(4시 반~8시) 복숭아빛, 낮 맑음, 해 질 녘(4시 반~8시) 노을빛, 밤 남색 + 작은 별. 하늘 그림 자체는 인생의 계절
- [ ] 하루가 눈 흰자 안을 봄 (눈동자가 흰자 밖으로 나가거나 흰자 위가 잘리지 않음)
- [ ] 폰을 움직이면 눈동자가 따라 굴렀다가, 가만히 두면 천천히 정면으로 돌아옴. 가끔 저절로 깜빡임
- [ ] 첫날엔 이끼 방석 하나. 누르면 생긴 날과 한 줄
- [ ] 아래로 넘기면 정원이 옅어지며 둘째 장(흐르는 시간 4줄 · 인생 달력)이 떠오름. 중간에 손을 떼면 가까운 장으로 부드럽게 넘어감. 주 단위 달력에서도 끊김 없이
- [ ] 문장이 길면 두 줄 안에 들어가게 글자가 조금 작아짐. 한국어가 낱말 중간에서 끊기지 않음
- [ ] 둘째 장 맨 아래 **모은 것** · **응원하기**
- [ ] 그 아래 **오늘의 한 줄**: 마음(기쁨 · 희망 · 평온 · 고마움 · 실망 · 슬픔 · 걱정, 안 골라도 됨) + 한 줄(60자) → **떠나보내기** → 글이 깃털과 함께 떠올라 사라지고, 화면 아래에 마음에 맞춘 한마디가 잠깐 떠오름 (누르면 닫힘). 하루에 한 번
- [ ] 1년 뒤 오늘: 개발자 모드 → 설정 ‘시험: 1년 전 오늘 한 줄 넣기’ → 홈 둘째 장 맨 아래에 ‘1년 전 오늘… 돌아왔어요’ 카드 → 펼쳐 보기 → 다시 보내기. 알림을 켜 두면 그날 아침 알림도
- [ ] 이어 쓰기 흔적: 7일 · 30일 · 100일 이어 쓰면 정원에 바람개비 · 종이배 · 연 (개발자 모드 ‘모두 미리 보기’로 그림 확인)
- [ ] 설정 → 오늘의 한 줄: 기록 남기기 끄기(날짜만 남음), 내보내기(공유 창), 모두 지우기(정원에 놓인 것은 남음)
- [ ] 키보드가 올라와도 입력칸이 가려지지 않음
- [ ] 글자와 그림이 겹치는 곳이 없는지

## 3. 모은 것 · 응원하기
- [ ] 모은 것: 지금까지 정원에 놓인 것만 (빈칸 · 개수 없음). 누르면 생긴 날과 한 줄
- [ ] 응원하기: 촛불 · 찻잔 그림 가운데 내 하루, 3단계(차 · 커피 · 케이크). 누르면 ‘시험판이라 결제가 아직 열리지 않았다’는 안내 (결제는 Play 스토어 등록 뒤)
- [ ] 설정에서도 들어갈 수 있음 (모은 것은 정원 디자인일 때)

## 4. 설정
- [ ] **디자인**에서 유리 ↔ 정원 바꾸기 (홈 · 위젯이 함께 바뀜)
- [ ] 내 하루 번호, 문장 언어, **아침 알림** (켜면 권한을 묻고, 매일 아침 7시 무렵 한 번)
- [ ] 생년월일 · 나라를 바꾸고 완료 → 숫자 · 계절 · 하루 자리가 바뀜
- [ ] 모든 기록 지우기 → 처음 화면 (새 하루를 만남)
- [ ] (시험용) 맨 아래 버전 글자를 7번 누르면 개발자 모드 → ‘놓이는 것 모두 미리 보기’

## 5. 위젯
- [ ] 홈 화면 빈 곳 길게 누름 → 위젯 → Carpe Diem: 남은 날(작게) · 오늘(작게) · 인생 달력(4×2, 4×4)
- [ ] 정원 디자인이면 종이 · 하늘 · 하루 그림, 유리 디자인이면 이전 모양

## 6. 유리 버전
- [ ] 홈 맨 아래에 **오늘의 한 줄**(유리 모양, 그림 없이)과 **응원하기** 카드
- [ ] 한 줄을 보내면 같은 한마디가 화면 아래에 떠오름. 설정에 ‘오늘의 한 줄’ 항목

## 7. 이번에 바뀐 것
- [ ] 홈 맨 위에 ‘Carpe Diem · 오늘을 소중히.’가 늘 보임 (정원 · 유리)
- [ ] 위젯 목록에 ‘남은 날 · 유리 / 정원’, ‘오늘 · 유리 / 정원’, ‘인생 달력 · 유리 / 정원’ 6가지
- [ ] 설정 → 보기 기본값: 남은 시간 단위 · 인생 달력 한 칸. 홈에서 바꾸면 그때만, 앱을 다시 열면 기본값
- [ ] 한 줄을 보내면 깃털이 위에서 흩날리며 내려오고, 한마디 창 → **확인**으로 닫힘
- [ ] 문득 찾아오는 한 줄: 개발자 모드 → ‘시험: 지난 한 줄이 문득 찾아오게’ → 홈에 ‘문득, …에 보낸 한 줄이 다시 찾아왔어요’ (평소엔 5~20일에 한 번쯤 아무 날)
- [ ] 입력칸을 누르면 키보드 위로 입력칸 · 보내기 버튼이 올라옴 (정원 · 유리)
- [ ] 정원에서 조금만 끌어내려도 둘째 장으로 넘어감
- [ ] 정원 인생 달력이 조약돌 모양 (위젯 정원 달력도)
- [ ] ‘이끼 방석’, ‘처음 앉은 자리’처럼 글자 모양이 섞이지 않음

## 8. 새 하루 (벡터)
- [ ] 하루가 단색 몸 · 먹선 · 동그란 눈으로, 훨씬 작게. 앱을 켜자마자 바로 보임 (‘그리는 중’ 없음)
- [ ] 밤 10시 ~ 아침 6시: 눈꺼풀이 위에서 반쯤 내려온 졸린 눈. 흰자와 눈동자가 어긋나지 않음
- [ ] 깜빡일 때 눈꺼풀이 내려왔다 올라감 (눈이 납작해지지 않음)
- [ ] 위젯의 하루도 같은 모습

## 9. 가족의 정원 (1.1)
- [ ] 정원 둘째 장 · 설정 → ‘가족의 돌 더하기’: 누구 → 이름 → 생일(모름 가능) → 만남 (다른 돌 3번까지)
- [ ] 돌 다섯까지 한 줄에 겹치지 않게, 비켜 앉은 돌은 원래 자리에 눈금 · 점선, 돌 아래 이름표
- [ ] 반려동물 돌은 조금 작게 (귀 없음)
- [ ] 한 번 누르면 웃는 눈 + 살랑 + 진동, 3초 안에 또 누르면 볼, 또 누르면 폴짝. 너무 많이 누르면 눈 감고 쉼
- [ ] 두 번 누르면 그 돌의 페이지 (옅어지며 다가옴): 만난 날 · 함께한 날 · 다음 생일 · 조약돌 달력(함께한 해 호박빛 테두리, 남은 칸은 스위치로) · 보낸 마음 · 고치기 · 내려놓기
- [ ] 생일인 돌: 작은 고깔모자, 돌 앞 작은 케이크, 아침 알림(켜 둔 경우), 오늘의 한 줄 ‘누구에게’에 먼저 골라짐
- [ ] 한 줄을 ‘엄마’에게 기쁨 · 고마움 · 희망으로 보내면 창 제목이 ‘엄마에게 보냈어요’, 정원의 엄마 돌 곁에 깃털
- [ ] 위젯 ‘가족의 정원 · 정원’ 4×2
- [ ] 개발자 모드 없이도 설정 ‘내 하루’를 누르면 내 돌의 페이지

## 10. 숨 (1.2)
- [ ] 정원의 내 하루를 길게 누르기 · 둘째 장 ‘숨, 쉼’ · 내 돌의 페이지 → 숨 고르기 창 (고요한 호흡 · 마음 산책 · 잠드는 명상 / 1 · 3 · 5분 / 소리: 없음 · 파도 · 바람 · 빗소리 · 잔잔한 파장)
- [ ] 시작에 종소리 한 번, 끝에 두 번. 바탕 소리가 스르르 켜지고 꺼짐 (파도 · 파장은 숨을 따라 밀려왔다 빠짐)
- [ ] 하루가 들이쉴 때 부풀어 떠오르고 내쉴 때 가라앉음, 3초 뒤 지긋이 눈 감음. 글자는 첫 1분만, 단계가 바뀔 때 짧은 진동
- [ ] 화면을 누르거나 뒤로 가기 → ‘여기서 멈출까요?’. 끝나면 한 줄 + 정원으로. 처음 숨 쉰 날 정원에 ‘작은 풍경’
- [ ] 밤 10시 이후 홈 문장 아래 ‘하루를 마무리하는 호흡’ → 잠드는 명상 1분
- [ ] 숨 쉬는 화면은 바탕 한 빛 · 작은 하루 · 선 하나뿐 (그림 없음)
- [ ] 둘째 장 ‘돌멍하기’: 홈의 정원에서 글자만 뺀 화면 (하늘 · 해와 달 · 땅 · 돌), 5분 뒤 스르르 어두워짐, 오른쪽 위 소리 끄고 켜기

## 11. 1.1.2 (밤의 정원)
- [ ] 저녁 8시 ~ 아침 6시 반: 폰 테마와 상관없이 정원이 어두운 남색. 글자 · 상자 선이 밝은 색으로
- [ ] 밤: 옅은 달빛, 돌들 발치의 은은한 빛, 오른쪽 끝 가로등, 반딧불 두 마리, 별 몇 개 (과하지 않은지)
- [ ] 아침 6시 반 ~ 8시 옅은 복숭아빛, 낮 맑음, 해 질 녘 노을빛은 어두워질 때까지 머묾
- [ ] 돌 아래 점선이 없어짐 (돌은 제자리 근처에 비켜 앉기만)
- [ ] 가족 고치기 · 더하기에 ‘함께한 첫날 (선택)’: 정하면 ‘함께한 지 N일’이 그날부터
- [ ] 정원 위젯도 밤에는 어두운 그림 + 밝은 글자

## 12. 깨닫기 (1.3)
- [ ] 일주일에 두 요일, 홈 문장 자리에 ‘오늘의 질문’ (예: 오늘 본 하늘은 어떤 색이었나요?)
- [ ] ‘한 줄로 답하기’ → 둘째 장 맨 아래로 넘어가고 입력칸 위에 질문. 보내면 평소처럼 깃털 · 한마디
- [ ] ‘오늘은 문장으로’ → 그날은 문장으로 돌아가고 다시 묻지 않음. 이미 한 줄을 보낸 날은 질문만
- [ ] 둘째 장 인생 달력 아래 ‘마음의 기록’: 이번 달의 날들이 그 달의 별자리로 (낮엔 꽃, 밤엔 별). 쉰 날은 옅은 점, 오지 않은 날은 더 옅게
- [ ] 3 · 6 · 9 · 12월 1일 (앞 석 달 한 줄 3개 이상): 둘째 장 맨 위 봉투 → 편지. 슬픔 · 걱정 · 실망은 ‘흘려보낸 마음 N번 · 함께 보기’
- [ ] 편지를 펼치면 봉투는 사라지고 모은 것 아래 ‘받은 편지’에 남음
- [ ] 설정에서 기록 남기기를 끄면 마음의 기록 · 편지가 보이지 않음
- [ ] 개발자 모드가 아니어도 확인하려면: 폰 날짜를 12월 1일로 (한 줄이 석 달 안에 3개 이상일 때)

## 13. 1.3.1
- [ ] 폰 언어 한국어면 홈 화면 이름 ‘하루의 정원’, 영어면 ‘Carpe Diem’
- [ ] 가족의 돌을 8개까지 더할 수 있음 (나 포함 9). 6개 이상이면 이름표가 두 줄로 번갈아 겹치지 않음
- [ ] 설정 맨 아래 ‘소개 · 문의 · 고지사항’ 을 누르면 작은 창. 버전 글자를 여러 번 누르면 개발자 모드
- [ ] 오늘의 문장이 새 문장들로 (예: 사람은 오직 지금, 이 스쳐 가는 순간만을 산다.)

## 14. 돌봄 (1.4)
- [ ] 슬픔으로 한 줄을 보내면 한마디 창 ‘확인’ 아래 ‘숨, 쉼 1분 함께할까요?’ → 누르면 고요한 호흡 1분
- [ ] 걱정 → ‘마음 산책으로 1분만 쉬어 갈까요?’, 실망 → ‘30초만 먼 곳을 바라볼까요?’ (동그라미가 30초 동안 차오르고 ‘잘 쉬었어요.’)
- [ ] 기쁨 · 고마움 (가족이 있고 ‘누구에게’를 안 골랐을 때) → 가족 이름을 누르면 그 돌 곁에 깃털
- [ ] 오늘 이미 숨을 쉬었으면 숨은 권하지 않음. 설정 ‘작은 권유’를 끄면 아무것도 권하지 않음
- [ ] 모은 것 아래 ‘고마움 책’ (옆으로 넘기기), ‘지금까지 N번 흘려보냈어요.’
- [ ] 슬픔 · 걱정 · 실망을 보낸 날 내 하루가 살짝 아래를 봄 (다음 날 평소대로)
- [ ] 가족 8개 (나 포함 9): 돌이 모두 길 안에, 이름표 두 줄
- [ ] 돌 고치기 맨 아래 ‘기억의 돌로 두기’ → 확인 → 정원 · 위젯 · ‘누구에게’에서 사라지고 모은 것 → 기억의 자리에 눈 감은 돌
- [ ] 돌 더하기 첫 장 맨 아래 ‘곁을 떠난 가족 · 반려동물’ → 이름 · 날(선택) → 기억의 자리에
- [ ] 기억의 자리: 숫자 없이 ‘2011년 봄부터 2024년 겨울까지’ (적었을 때만), 한 줄 보내기 (돌마다 하루 한 번), 보낸 마음 펼쳐 보기, 다시 정원으로 · 내려놓기
- [ ] ‘하늘에 별로 두기’ (기본 켬): 홈 하늘에 따뜻한 별, 누르면 ‘이름 · 여기 조용히 있어요’ 잠깐. 끄면 사라짐. 돌멍하기에는 없음
- [ ] 기억의 돌에게 보낸 한 줄은 오늘의 한 줄 · 회상 · 계절의 편지 · 마음의 기록에 나오지 않음, 알림 없음

## 18. 별자리 정원 · 알림 셋 · 생일 전날 (1.8)
- [ ] 마음의 기록을 누르면 시트: 위에 월 · 해. 월은 ‹ › 로 지난 달, 날을 누르면 날짜와 그날의 한 줄 (쉰 날 · 글 없이 보낸 날은 그렇게)
- [ ] 해: 열두 별자리가 띠를 따라 아주 천천히 흐름, 손가락으로 밀면 멈추고 따라옴. 아래에 지금 가운데 있는 달 · 별자리 이름
- [ ] 낮엔 꽃, 밤엔 별. 별자리를 닮았지만 고르지 않게 흩뿌려진 무늬, 같은 달도 해마다 다름. 몇 초에 하나씩만 살랑 · 반짝. 애니메이션 끄기면 멈춘 그림
- [ ] 달이 바뀐 뒤 사흘 둘째 장 위에 ‘○월의 정원이 피었어요’ (밤엔 ‘별이 떴어요’), 누르면 그 달
- [ ] 모은 것 › 지난 정원: 해 이름 (누르면 한 해), 아래 열두 달 칸 (누르면 그 달, 오지 않은 달은 빈 칸)
- [ ] 그림으로 보내기: 한 달 · 한 해 (열두 별자리 4 × 3), 밤에 보내면 남색 바탕
- [ ] 설정 알림 셋: 아침 알림 (7시) · 생일 · 특별한 날 알림 (전날 저녁 7시 · 그날 아침 9시, 그런 날만) · 하루 정리 알림 (밤 10시)
- [ ] 가족 생일 전날 저녁 5시부터: 그 돌이 고깔, 정원 아래 ‘내일은 엄마 생일이에요’, 돌 페이지에 같은 말 · ‘다음 생일까지 내일이에요’ · 생일 카드 보내기
- [ ] 생일 당일: 고깔 + 케이크, ‘오늘은 엄마 생일이에요’. 다음 날엔 평소대로
- [ ] 생일 카드: 나와 엄마의 작은 돌 사이에 케이크와 하트, 낮엔 깃발 줄 · 밤엔 전구 줄과 별

## 18-1. 하루를 열고 닫는 의식 · 추억 (비공개 테스트 2차)
- **알림에서 바로 한 줄**: 하루 정리 알림을 아래로 내려 ‘한 줄 쓰기’로 답장하면 앱을 열지 않고 남아요. 보낸 뒤 알림에서 기쁨 · 평온 · 걱정 중 마음 하나를 고를 수 있어요. 오늘 이미 썼으면 그 아래 줄로 덧붙어요.
- **바로 가기**: 앱 아이콘을 길게 누르면 오늘의 한 줄 · 숨, 쉼 1분 · 돌멍하기 · 하루 닫기가 떠요.
- **하루 닫기**: 저녁 7시 이후 정원 위쪽 ‘하루 닫기 · 1분’, 또는 하루 정리 알림을 누르면 시작해요. 한 줄 → 고마운 것 떠올리기 (숨 세 번) → 등불 아래 숨 두 번 → ‘등불 끄기’. 어느 걸음에서든 ‘여기까지’로 끝낼 수 있어요.
- **아침 씨앗**: 아침 (5–11시) 정원 아래 ‘오늘 마음에 씨앗 하나 심을까요?’. 심으면 하루 발치에 새싹이 나고, 저녁에 한 줄을 남긴 뒤 ‘싹이 텄나요?’ 하고 물어요. 핀 씨앗은 추억 탭에. 설정 › 오늘의 한 줄에서 끌 수 있어요.
- **하루의 숨결 (손끝으로)**: 숨, 쉼 창에서 ‘손끝으로’를 고르면 숨을 떨림으로 느껴요. 6초 뒤 화면이 거의 까매지고, 한 번 누르면 잠깐 밝아지고, 길게 누르면 멈춰요.
- **걱정한 밤 다음 아침**: 어제 걱정 · 슬픔 · 실망으로 한 줄을 남겼다면, 오늘 처음 정원을 열 때 하루가 위로 한마디만 건네요 (묻는 것 없음).
- **미래의 나에게**: 추억 탭 ‘미래의 나에게 쓰기’, 또는 계절 첫날의 바람 카드에서 ‘언제 열까요?’ (다음 생일 · 1년 뒤). 열리는 날까지 나무 밑에 작은 흙더미가 있고, 그날 아침 ‘나무 밑 항아리가 열렸어요’.
- **생일 아침의 나이테**: 생일 아침 ‘N번째 나이테가 생겼어요’ → 열두 달 마음의 고리, 한 해 걸어보기, 다음 생일에 열 편지. 추억 탭 ‘나이테’에서도 볼 수 있어요.
- **한 해의 엔딩 크레딧**: 추억 탭에서 해를 고르면 1분 남짓 (인트로 · 네 계절 · 아웃트로). 12월 21일부터는 정원 아래에도 알려요. 누르면 멈춤, ‘건너뛰기’는 끝으로.
- **정원 손님**: 앱을 열든 안 열든 평균 일주일에 한 번, 사람마다 다른 날에 손님(곤줄박이 · 다람쥐 · 고슴도치, 드물게 토끼 · 부엉이)이 놀러 와요. 그날 처음 정원을 열면 손님 이야기 카드가 잠깐 뜨고, 손님은 하루 종일 말뚝 발치에 있어요. 만난 손님은 추억 › 만난 순간과 엔딩 크레딧 ‘특별 출연’에 남아요. 캡처: `--es cd.guest tit`.
- **사진 한 장**: 한 줄을 쓸 때 ‘사진 한 장’ (보낸 뒤에도 그날 안에 붙이기). 원본 대신 작은 사본만 남고, 한지 액자에 바랜 모습으로 보여요. 시간이 지날수록 조금씩 더 바래요. 기록 옮기기 파일에 함께 담겨요.
- **앱 첫 화면**: 아이콘으로 켤 때마다 (30분 넘게 떠났다 돌아와도) 타이틀 화면. 어디든 누르면 하루가 눈을 뜨고 정원이 동그랗게 열려요. 알림 · 위젯 · 바로 가기로 열면 건너뛰어요. 설정 › 디자인에서 끌 수 있어요.
- **돌아온 한 줄**: 펼치면 ‘카드로 간직’ · ‘오늘 한 줄에 이어 쓰기’.
