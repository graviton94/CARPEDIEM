# 폰 테스트 안내 (Android 완성 테스트판)

설치는 [android-install.md](android-install.md). 처음 켜면 **정원** 디자인으로 시작합니다.

## 1. 처음 켜기
- [ ] 생년월일 · 나라 · 성별을 넣고 **시작** → “하루를 만났습니다.” 화면 (반짝이는 여기서만)
- [ ] 1~2초 “하루를 그리는 중…” 뒤에 하루가 나타남 → **정원으로**

## 2. 정원 (홈)
- [ ] 하늘에 남은 시간, 일 · 주 · 개월 · 년 칩, 오늘의 문장
- [ ] 문장을 누르면 다음 문장 + 하루가 한 번 깜빡임
- [ ] 땅 한 줄 = 지나온 길: 왼쪽 0세, 오른쪽 기대수명, 하루 아래 ‘만 N세 · 인생의 계절’
- [ ] 해(밤에는 달)가 지금 시각 자리에 있음. 밤 10시 ~ 아침 6시엔 하루가 졸린 눈
- [ ] 폰을 옆으로 기울이면 눈동자가 따라감. 가끔 저절로 깜빡임
- [ ] 첫날엔 이끼 방석 하나. 누르면 생긴 날과 한 줄
- [ ] 아래로 넘기면 흐르는 시간 4줄 · 인생 달력 (1칸 단위 바꾸기)
- [ ] 글자와 그림이 겹치는 곳이 없는지

## 3. 설정
- [ ] **디자인**에서 유리 ↔ 정원 바꾸기 (홈 · 위젯이 함께 바뀜)
- [ ] 내 하루 번호, 문장 언어, **하루 한 번 알림** (켜면 권한을 묻고, 매일 아침 8시 50분 무렵 한 번)
- [ ] 생년월일 · 나라를 바꾸고 완료 → 숫자 · 계절 · 하루 자리가 바뀜
- [ ] 모든 기록 지우기 → 처음 화면 (새 하루를 만남)
- [ ] (시험용) 맨 아래 버전 글자를 7번 누르면 개발자 모드 → ‘놓이는 것 모두 미리 보기’

## 4. 위젯
- [ ] 홈 화면 빈 곳 길게 누름 → 위젯 → Carpe Diem: 남은 날(작게) · 오늘(작게) · 인생 달력(4×2, 4×4)
- [ ] 정원 디자인이면 종이 · 하늘 · 하루 그림, 유리 디자인이면 이전 모양

## 5. 여러 조건
- [ ] 다크 모드: 정원은 밝은 종이 그대로, 상태바 글자가 보임 / 유리는 어두운 화면
- [ ] 폰 언어 영어, 글자 크게, 작은 폰
- [ ] 애니메이션 끄기(개발자 옵션 · 접근성): 깜빡임 · 눈동자 굴림이 멈춤

## 알아 두기
- 놓이는 것은 시간이 흐르면 저절로 생깁니다 (7일 · 100일 · 1년 · 계절 · 생일 · 새해 · 문장 넘김 · 30일 만에 돌아옴 · 인생의 계절). 개수나 빈칸은 보이지 않습니다.
- 계절은 북반구 기준입니다.
- 아직 없는 것: 응원하기, 테마 6가지, iOS 정원 버전.
- 화면 캡처(에뮬레이터): 저장소의 `screenshots-android` 브랜치.
