## 1.1.5 를 합침 (2026-10-14)

같은 출발점 (`0daeaa9`) 에서 따로 쌓인 1.1.5 작업 (브랜치 `ccr-9c057d87-02205t`, 33 커밋, 테스트 빌드 #248) 을 1.1.6 에 합쳤다. 테스터 폰에 이미 있는 것들이라 빠지면 안 됨.

| 들어온 것 | 내용 |
|---|---|
| 아침 이슬 | 그날 첫 아침, 첫 화면 → 이슬 → 정원. 손끝으로 김을 닦아 하루를 깨움 |
| 간직한 문장 | 정원의 문장을 길게 눌러 간직, 못 만난 것은 실루엣 |
| 숨 종 | 바탕 소리에 맞춘 다섯 가지 종 (싱잉볼 · 풍경 · 대나무 · 목탁 · 크리스털), ‘소리 없음’ 은 무음 |
| 그림 | 정원 물건 · 손님 · 응원 그림을 손선 한지로 |
| 설정 · 알림 | 설정 덜어냄, 알림 세 줄, 시각은 휠로 |
| 응원 | Play 결제가 열릴 때까지 응원 권유 숨김 |

합칠 때: 하루의 눈맞춤 (`glance`) 과 이슬 (`smileKick` · 눈꺼풀) 을 함께, 정원이 피어나는 차례 (`bloom`) 와 눈맞춤을 함께 둠.
그쪽 기획의 ‘창가의 하루 위젯 (톡 → 깜빡)’ 은 Glance 가 움직임을 못 그려 이번에도 뺌.

## 비공개 테스트와 일정

- Play 의 프로덕션 액세스 조건은 **신청하는 때에 테스터 12명이 지난 14일 동안 이어서 참여 중** 인 것. 1.1.6 을 만드는 동안에도 테스터가 빠지지 않게 둔다.
- 중간 빌드 (1.1.5 · 1.1.6 후보) 를 비공개 트랙에 올리고 테스터 의견을 받는 것은 신청 답안의 근거가 된다.
