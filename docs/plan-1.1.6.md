## 비공개 테스트와 일정

- Play 의 프로덕션 액세스 조건은 **신청하는 때에 테스터 12명이 지난 14일 동안 이어서 참여 중** 인 것. 1.1.6 을 만드는 동안에도 테스터가 빠지지 않게 둔다.
- 중간 빌드 (1.1.5 · 1.1.6 후보) 를 비공개 트랙에 올리고 테스터 의견을 받는 것은 신청 답안의 근거가 된다.

## 출시 순서 (1.1.6 검증 뒤)

1. `design/changelog.json` 에 1.1.6 (1.1.5 내용 포함) → `scripts/generate.py`
2. Actions › Android release (Play) `1.1.6` → 비공개 트랙 → 위 검증
3. 고친 스토어 문안 (`docs/store-listing.md`) · 새 캡처를 Play Console 에
4. 프로덕션 액세스 신청 (테스터 12명 · 14일 이어서 참여 확인). 답안: 테스터 의견 (진동 · 숨 빠르기 · 말 안내 · 잠들기) → 1.1.5 · 1.1.6 에서 바꾼 것
5. 승인 뒤 같은 AAB 를 프로덕션으로, 단계적 출시 (20% → 50% → 100%)
