# 오늘의 명언

원본: `data/quotes.csv` (100개, 열: `No`, `한글`, `영문`). 작가·출처 정보는 없습니다.

## 고르는 규칙 (제안)

1. **하루 한 개.** 기기 시간으로 자정에 바뀝니다. 앱과 위젯이 같은 명언을 보여줍니다.
2. **무작위이되 겹치지 않게.** 처음 실행할 때 100개의 순서를 무작위로 섞어 기기에 저장하고, 하루에 하나씩 넘깁니다. 100일 동안 같은 명언이 다시 나오지 않습니다.
3. **한 바퀴를 다 돌면 다시 섞습니다.** 이때 새 순서의 첫 명언이 바로 전날 명언과 같지 않게 합니다.
4. **앱에서 명언을 누르면 다음 명언.** 그날 명언이 마음에 안 들 때 넘겨볼 수 있고, 다음 날에는 원래 순서로 돌아갑니다. (선택 기능)

## 보여주는 방식 (제안)

- 한글을 크게, 영문을 그 아래 작게 둡니다. 설정에서 한글만 · 영문만 · 둘 다 중에 고를 수 있습니다.
- 가장 긴 명언은 한글 90자, 영문 176자입니다. 레이아웃은 이 길이를 기준으로 맞춥니다.
- 작은 위젯에는 넣지 않고, 앱 홈과 큰 위젯(인생 달력)에만 넣습니다. 큰 위젯에서는 한글만 최대 3줄까지 보여줍니다.
