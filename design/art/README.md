# 하루의 정원 그림 (시안 2 · 손그림)

철학: 마음이 쉬는 곳 · 단순하게 · 돌멩이 · 느리고 고요하게.
매끈한 도형이나 그러데이션 대신, 종이 위에 연필과 파스텔로 그린 방식을 코드로 흉내 냅니다.

- 파스텔: 짧은 붓질 수백 개를 겹치고, 종이 결(튀어나온 곳)에만 색이 묻게 거릅니다. 밝고 어두움은 붓질 밀도로 만듭니다.
- 연필: 필압이 변하고, 두 번 긋고, 군데군데 끊깁니다.
- 하늘은 대부분 종이 그대로 비워 둡니다 (글자 자리). 빛은 왼쪽 위.

원본 코드: `src/` — `pastel.js` 종이 · 파스텔 · 연필과 하루 손그림, `objects.js` 놓이는 것 12가지, `scenes.js` 계절 · 테마 · 후원 · 스토어, `engine.js` 하루 번호 규칙.
다시 굽기: `node scripts/build_art.js` (Playwright 필요)

하루(조약돌)는 번호마다 달라서 파일로 굽지 않습니다. 앱이 같은 손그림 방식으로 처음 한 번 그려 저장해 둡니다. 배경 파일에는 하루와 놓이는 것이 들어 있지 않습니다.

## 그림체 시안 (진행 중)
`src/concepts.js` — 같은 장면을 여러 손그림 방식으로 그리는 시안 코드입니다. `MIX`(크레용 파스텔: 굵은 크레용 선 + 선에서 살짝 어긋난 파스텔 채움 + 옅은 크레용 결)가 2안 + 3안을 합친 안입니다. 확정되면 놓이는 것 · 배경을 이 방식으로 다시 굽습니다.
